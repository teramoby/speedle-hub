Speedle 패밀리

하나의 정책 모델. 앱, 서비스 및 AI 에이전트

Speedle은 팀 누구나 쉽게 읽고 이해할 수 있는 정책 언어 SPDL을 기반으로 구축된 오픈 소스 인가 엔진입니다. Speedle Engine을 통해 자체 호스팅하거나, 무료 공개 베타로 제공되는 Speedle Cloud를 살펴보거나, Speedle AI를 사용하여 동일한 모델을 AI 에이전트에 적용할 수 있습니다.

Speedle Engine

자체 인프라에서 인가 시스템을 직접 운영하려는 팀을 위한 제품입니다.

RBAC 및 ABAC 정책을 지원하는 Go 언어 기반 인가 엔진입니다. SPDL을 평가하고, 정책 관리 서비스(PMS)를 통해 정책을 관리하며, 인가 결정 서비스(ADS)에서 결정을 내립니다. spctl CLI 및 6개 언어 SDK와 연동됩니다.

Speedle Cloud 출시 예정

직접 서버를 운영하지 않고 호스팅형 인가 API를 사용하려는 개발자를 위한 제품입니다.

동일한 정책 모델과 SPDL을 호스팅 환경에서 제공합니다: 서비스, 정책 및 토큰 관리를 위한 콘솔, 플레이그라운드, IsAllowed API. 현재 샘플 데이터를 기반으로 한 라이브 데모를 체험할 수 있으며, 곧 로그인이 열리고 토큰 인증 API 호출이 순차 적용됩니다.

Speedle AI

AI를 활용해 접근 권한을 관리하려는 팀과 AI의 접근 권한을 통제해야 하는 팀을 위한 제품입니다.

AI로 접근 권한 관리: 오픈 소스 정책 모델러 Agent Skill이 지침서와 규정을 테스트 가능한 SPDL 모델로 변환합니다. AI의 접근 권한 통제: 데이터 및 학습, 모델 배포, 권한 인식 RAG, 에이전트, MCP 도구 호출, 에이전트 간 호출(A2A), 상시 권한 배제(ZSP)에 대한 SPDL 패턴을 지원합니다.

MCP 서버는 출시 프리뷰 단계입니다. AI 패턴은 Speedle 엔진 위에서 작동하는 솔루션 패턴입니다.

단일 엔진, 단일 정책 언어, 단일 요청 모델이 세 제품을 유기적으로 연결합니다. Speedle Cloud는 Engine과 동일한 SPDL 의미 체계를 실행하므로 자체 호스팅 Speedle에서 작성한 정책을 Speedle Cloud로 그대로 마이그레이션할 수 있습니다.

01

하나의 엔진, 하나의 정책 언어

Speedle Engine은 오픈 소스 구현체입니다. Speedle Cloud는 동일한 정책 모델, SPDL 및 결정 체계를 실행합니다. Speedle AI는 동일한 엔진을 AI 시스템에 적용합니다.

02

자체 호스팅 또는 클라우드 호스팅 선택

Engine을 통해 자체 인프라에서 전체 스택을 실행하거나, 무료 공개 베타인 Cloud를 사용하여 정책을 저장하고 IsAllowed 요청에 응답할 수 있습니다. Cloud API는 Speedle ADS와 호환됩니다.

03

그 위에 AI 기능 추가

Speedle AI는 AI 지원 정책 모델링과 AI 에이전트를 위한 정책 패턴을 추가합니다. 이는 기존 엔진과 Cloud를 대체하는 것이 아니라 그 위에 구축됩니다.

policy.spdl 
# Speedle Cloud 데모 정책
grant role reader get /books
deny user bob delete /books
grant user alice reader on /books

Speedle Cloud 데모에 포함된 SPDL 예제입니다. Speedle Engine과 Speedle Cloud는 동일한 정책 언어를 사용합니다.

6개 언어 SDK를 통해 인가 API를 호출하며, Speedle MCP 서버는 MCP 클라이언트에 인가 확인 및 정책 관리 기능을 제공합니다.

6개 언어를 위한 SDK

6개 SDK 모두 POST /authz-check/v1/is-allowed를 호출합니다. Python, Java, Go, C#/.NET 및 Rust는 0.2.0 버전으로 출시되었으며, Node.js 패키지 @speedle/sdk는 npm에 배포되었습니다. 모두 자체 호스팅 Speedle을 지원하며, Speedle Cloud 지원도 곧 제공될 예정입니다.

npm install @speedle/sdk

Speedle MCP

출시 프리뷰 단계인 로컬 stdio MCP 서버로, 인가 확인을 위한 check와 정책 관리를 위한 manage라는 두 가지 독립된 모드를 제공합니다. @speedle/mcp는 npm에 배포되어 있으며, 실행 바이너리는 speedle-mcp로 npx를 통해 직접 실행할 수 있습니다.

npm install @speedle/mcp
npx @speedle/mcp check
