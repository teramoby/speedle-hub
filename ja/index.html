Speedle ファミリー

1 つのポリシーモデル。アプリ、サービス、AI エージェントに対応

Speedle は、チーム全員が理解できるポリシー言語 SPDL を中核としたオープンソース認可エンジンです。Speedle Engine で自社運用するほか、無料パブリックベータの Speedle Cloud を試すことや、Speedle AI で同じモデルを AI エージェントへ適用できます。

Speedle Engine

自社のインフラストラクチャ上で認可を実行したいチーム向け。

RBAC および ABAC ポリシーに対応した Go 言語製認可エンジンです。SPDL を評価し、ポリシー管理サービス（PMS）でポリシーを管理し、認可決定サービス（ADS）から決定を提供します。spctl CLI および 6 つの SDK と連携します。

Speedle Cloud まもなく公開

自前でサーバーを運用することなく、ホスト型の認可 API を利用したい開発者向け。

同じポリシーモデルと SPDL をクラウドでホスト：サービス、ポリシー、トークンを管理するコンソール、プレイグラウンド、IsAllowed API を提供します。現在はサンプルデータを用いたデモを公開しており、まもなくログインが開始され、トークン認証付き API 呼び出しも順次展開されます。

Speedle AI

AI を活用してアクセス権を管理したいチーム、および AI のアクセス先を適切に制御したいチーム向け。

AI でアクセス権を管理：オープンソースのポリシーモデラー Agent Skill により、規程やマニュアルをテスト済みの SPDL モデルへと変換します。AI のアクセス権を制御：データとトレーニング、モデルリリース、権限を考慮した RAG、エージェント、MCP ツール呼び出し、エージェント間呼び出し（A2A）、常設特権ゼロ（ZSP）を SPDL パターンでカバーします。

MCP サーバーはローンチプレビュー段階です。AI パターンは Speedle エンジン上で動作するソリューションパターンです。

連携の仕組み

最初のサービスから最初のエージェントまで、共通のポリシー

1 つのエンジン、1 つのポリシー言語、1 つのリクエストモデルが 3 つのプロダクトを結びつけます。Speedle Cloud は Engine と同じ SPDL セマンティクスを実行するため、セルフホストの Speedle から Speedle Cloud へとポリシーをシームレスに移行できます。

01

1 つのエンジン、1 つのポリシー言語

Speedle Engine はオープンソースの実装です。Speedle Cloud は同じポリシーモデル、SPDL、決定セマンティクスを実行します。Speedle AI は同じエンジンを AI システムに適用します。

02

セルフホストでもホスト型でも、自由に選択

Engine を使って自社インフラ上でフルスタックを実行することも、無料パブリックベータの Cloud を使ってポリシーを保持し IsAllowed リクエストに応答することも可能です。Cloud API は Speedle ADS と互換性があります。

03

その上に AI を追加

Speedle AI は、AI 支援によるポリシーモデリングと AI エージェント向けポリシーパターンを追加します。エンジンと Cloud を置き換えるのではなく、その基盤の上に構築されます。

policy.spdl 
# Speedle Cloud demo policies
grant role reader get /books
deny user bob delete /books
grant user alice reader on /books

Speedle Cloud デモの SPDL 例です。Speedle Engine と Speedle Cloud は同じポリシー言語を使用します。

アプリケーションコードやエージェントから

6 つの SDK が認可 API を呼び出し、Speedle MCP サーバーが認可チェックとポリシー管理を MCP クライアントにもたらします。

6 つの言語に対応した SDK

6 つの SDK はすべて POST /authz-check/v1/is-allowed を呼び出します。Python、Java、Go、C#/.NET、Rust は 0.2.0 として公開されており、Node.js パッケージ @speedle/sdk は npm で公開されています。すべてセルフホストの Speedle で動作し、Speedle Cloud のサポートもまもなく提供されます。

npm install @speedle/sdk

  • Python
  • Go

Speedle MCP

ローンチプレビュー版のローカル stdio MCP サーバーで、2 つの独立したモードを備えています。認可判定を行う check と、ポリシー管理を行う manage です。@speedle/mcp は npm で公開されており、バイナリ名は speedle-mcp です。npx から直接実行できます。

npm install @speedle/mcp
npx @speedle/mcp check
